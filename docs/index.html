BLUESOFT Design System

Figma DS Master를 코드화한 master SCSS 라이브러리. SI 프로젝트마다 이 저장소의 scss/를 복사해 사용합니다.

토큰은 3단 구조입니다: Primitive(원시값, CSS 커스텀 프로퍼티) → Semantic(의미 별칭) → Component(컴포넌트별 SCSS 변수). 컴포넌트 파일은 $변수를 그대로 쓰면 됩니다.

아이콘은 icons/sprite.svg 하나에 <symbol>로 묶여 있으며 <use href="assets/icons/sprite.svg#icon-base-check"> 형태로 참조합니다.
