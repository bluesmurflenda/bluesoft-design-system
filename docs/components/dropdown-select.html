Dropdown & Select

Dropdown — Trigger 사이즈

닫힌 상태(aria-expanded="false")의 트리거만 사이즈별로 나열합니다.

Dropdown — 조립 예시(열림 상태)

.dropdown__trigger[aria-expanded="true"] + .list-panel 조합. 옵션 상태는 default/selected(.list-item-selected)/disabled(.list-item-disabled)입니다.

Select — Size × Validation

라벨 + 필드(콘텐츠 텍스트 + chevron) + 힌트로 구성. 패널·옵션은 Dropdown의 .list-panel/.list-item을 재사용합니다.

Select — Disabled

검증 상태별로 확인합니다(md 사이즈). .select-disabled를 검증 modifier와 함께 사용합니다.

Select — 선행 아이콘 슬롯

.select__icon — .select__chevron과 나란히 필드 안에 놓이는 선택적 슬롯입니다(사이즈와 무관하게 고정 크기입니다).
