Dropdown & Select

Dropdown: Trigger 사이즈 4종(sm/md/lg/xl) + List Panel/Item 상태 3종(default/selected/disabled, 조립 예시 1개로 확인 — 사이즈 무관). Select: Size 4종(sm/md/lg/xl) × Validation 3종(normal/invalid/valid) = 12 + Disabled 3종(md 기준) = 15.

Dropdown — Trigger 사이즈

닫힌 상태(aria-expanded="false")의 트리거만 사이즈별로 나열합니다.

Dropdown — 조립 예시(열림 상태)

.dropdown__trigger[aria-expanded="true"] + .list-panel 조합. 옵션 상태는 default/selected(.list-item-selected)/disabled(.list-item-disabled) 3종입니다.

Select — Size × Validation

라벨 + 필드(콘텐츠 텍스트 + chevron) + 힌트로 구성. 패널·옵션은 Dropdown의 .list-panel/.list-item을 재사용합니다.

Select — Disabled

검증 상태별 3종(md 사이즈). .select-disabled를 검증 modifier와 함께 사용합니다.
