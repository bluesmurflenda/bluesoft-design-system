Pagination

숫자 셀 프리미티브 18(형태 2 원형/사각형 × 상태 3 default/current/ellipsis × 사이즈 3 sm/md/lg) + 캐노니컬 Type 5종(numbers/simple/simple-icon/numbers-buttons/button-group) × 사이즈 3 = 15 + Pagination Compact(모바일, 자체 사이즈 축 없음) 1 = 총 34 조합. hover는 정적 페이지로 재현할 수 없어 제외합니다.

Number 셀 프리미티브

.pagination-number(원형)와 .pagination-number-square(사각형, numbers-buttons·button-group 전용)는 모든 Type이 공유하는 셀입니다. 사이즈는 조상 요소의 .pagination-sm/md/lg가 결정합니다.

Type = numbers

테두리 없는 텍스트 Prev/Next + 번호. 위쪽 구분선(border-top). .pagination-numbers.pagination-{size} 조합.

Type = simple

"Page N of M" 텍스트 + Prev/Next 버튼(.btn .btn-outline 재사용). .pagination-simple.pagination-{size} 조합.

Type = simple-icon

아이콘 전용 Prev/Next(.icon-btn .icon-btn-outline 재사용) + "Page N of M". 테이블 하단 페이지네이션도 이 클래스를 재사용합니다. .pagination-simple-icon.pagination-{size} 조합.

Type = numbers-buttons

Prev/Next는 독립 버튼(.btn .btn-outline), 번호만 .pagination-group.pagination-{size}로 테두리 그룹에 묶입니다.

Type = button-group

Prev/Next까지 번호와 함께 .pagination-group.pagination-{size} 하나의 테두리 그룹에 묶입니다. Prev/Next는 .pagination__nav(아이콘+텍스트).

Pagination Compact(모바일)

Prev/Next 아이콘 버튼(.pagination-compact__nav, 32×32 고정, 사이즈 축 없음) + 번호 배지. .pagination-compact__numbers에는 전용 숫자 셀 클래스가 없어 .pagination-number를 그대로 재사용하며, 32px 크기를 맞추기 위해 .pagination-sm을 함께 얹었습니다.
