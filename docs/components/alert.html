피드백 컴포넌트 / Alert

Alert

Color 6종(brand/neutral/success/warning/error/info) × Layout 3종(inline/banner/toast) = 18. info는 brand와 라이트 모드에서만 bg/fg/border 값이 같습니다(Chip과 동일 패턴) — 서로 다른 토큰이라 다크에서는 fg·border가 갈립니다(brand는 blue-300, info는 blue-400 등). bg만 다크에서도 계속 같습니다.

Inline

본문 안에 배치하는 기본 레이아웃. 보더 + radius-lg. 폭 480px 고정.

Action

Action 1·Action 2 슬롯(button/tertiary/bg) — 기본 숨김, 필요할 때만 넣는다.

Banner

화면 상단 등 전체 폭에 걸치는 레이아웃. 보더 없이 배경색만 채워지고 border-radius: 0입니다(실측: inline/toast와 다름).

Toast

고정폭 400px + 그림자(Shadow/lg)가 있는 플로팅 카드 레이아웃.
