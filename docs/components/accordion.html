Accordion

펼침 여부는 트리거의 aria-expanded로 읽고 패널은 hidden 속성으로 감춥니다 — 상태 전용 클래스가 없습니다. 트리거 최소 높이와 라운드 반경은 Shape 컬렉션 토큰이라 [data-shape] 전환을 따라갑니다.

Container

컨테이너 장식이 네 가지입니다. 기본(클래스 없음)은 구분선만 있고, border는 바깥 테두리, rounded는 테두리와 라운드, each는 아이템마다 테두리·라운드를 갖고 space/2만큼 떨어집니다.

Size

트리거 최소 높이 44/56/64와 좌우 여백 16/20/24가 사이즈를 만듭니다. 제목·본문은 sm·md가 15/22, lg만 16/24입니다.

Meta

제목 오른쪽에 날짜 같은 보조 정보를 둘 수 있습니다. 사이즈와 무관하게 14/20이고 색은 text/tertiary입니다.
