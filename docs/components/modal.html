Modal

Layout 3종(form/alert-centered/alert-horizontal) × Breakpoint 4종(sm 300px/md 500px/lg 800px/xl 1000px) = 12. 폭 클래스(.modal-sm~.modal-xl)는 레이아웃과 무관하게 .modal에 직접 붙는 별도 축이라 3개 레이아웃 전부에 4개 breakpoint가 그대로 적용됩니다. 실제로는 open/close 상호작용이 있는 다이얼로그지만, 이 페이지에서는 정적 카드로만 렌더링합니다.

Form

전용 layout modifier 클래스가 없는 기본형 — .modal + breakpoint 클래스만 사용합니다. 헤더는 .modal-header-left(아이콘 없이 텍스트만), 본문은 .modal__slot 플레이스홀더, 액션은 기본 .modal__actions(가로 배치).

Alert Centered

.modal-alert-centered + .modal-header-center(아이콘·제목·설명 세로 중앙 정렬) 조합. 아이콘은 .modal-featured-icon(Featured Icon과 색상 커스텀 프로퍼티 공유). 액션은 .modal-actions-stacked로 세로 배치했습니다 — stacked/horizontal 액션 정렬은 레이아웃과 독립된 별도 modifier라 강제 규칙은 아니며, 아래는 자주 쓰이는 조합 예시입니다.

Alert Horizontal

.modal-alert-horizontal + .modal__content(Featured Icon과 헤더를 한 줄에 배치하는 wrapper) 조합. 액션은 기본 .modal__actions(가로 배치, stacked 아님).
