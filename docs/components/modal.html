Modal

Layout 3종(form/alert-centered/alert-horizontal) × Breakpoint(sm 300px/md 500px/lg 800px/xl 1000px) — 단 Figma엔 8변형만 있습니다: form은 4개 breakpoint 전부, alert-centered·alert-horizontal은 sm·md만(lg·xl 없음). 폭 클래스는 .modal에 직접 붙는 별도 축이라 CSS로는 어떤 조합도 가능하지만, .modal-lg·.modal-xl은 .modal-form에만 씁니다. 실제로는 open/close 상호작용이 있는 다이얼로그지만, 이 페이지에서는 정적 카드로만 렌더링합니다.

Overlay(딤드 배경)

.modal-overlay — 모달 뒤에 형제로 두는 딤드 배경(rgba(0,0,0,0.48)). 실제로는 position:fixed;inset:0로 뷰포트 전체를 덮지만, 이 페이지에서는 카드 안에 가두기 위해 position:absolute를 인라인으로 얹었습니다.

모달 제목
오버레이 위에 뜬 모습입니다.

Form

전용 layout modifier 클래스가 없는 기본형 — .modal + breakpoint 클래스만 사용합니다. 헤더는 .modal-header-left(아이콘 없이 텍스트만), 본문은 .modal__slot 플레이스홀더, 액션은 기본 .modal__actions(가로 배치).

Alert Centered

.modal-alert-centered + .modal-header-center(아이콘·제목·설명 세로 중앙 정렬) 조합. 아이콘은 .modal-featured-icon(Featured Icon과 색상 커스텀 프로퍼티 공유). 액션은 .modal-actions-stacked로 세로 배치했습니다 — stacked/horizontal 액션 정렬은 레이아웃과 독립된 별도 modifier라 강제 규칙은 아니며, 아래는 자주 쓰이는 조합 예시입니다. Figma에 lg·xl 변형이 없어 sm·md만 나열합니다.

Alert Horizontal

.modal-alert-horizontal + .modal__content(Featured Icon과 헤더를 한 줄에 배치하는 wrapper) 조합. 액션은 기본 .modal__actions(가로 배치, stacked 아님). Figma에 lg·xl 변형이 없어 sm·md만 나열합니다.
