Textarea

Size 3종(sm/md/lg) × Validation 3종(normal/invalid/valid) = 9. 여기에 Disabled를 검증 상태별 3종(md 사이즈, 실제 disabled 속성)으로 추가해 총 12종을 나열합니다.

Size × Validation 매트릭스

라벨 + 필드(textarea) + 힌트 텍스트로 구성된 기본 조립. 힌트 색상은 검증 상태를 따릅니다.

Disabled

검증 상태별 3종(md 사이즈). 실제 <textarea disabled>를 사용하며 힌트 텍스트는 40% 투명도로 흐려집니다.
