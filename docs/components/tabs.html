Tabs

Type 4종(underline/underline-brand/pill/segmented) × 사이즈 4(sm/md/lg/xl) × 상태 3(default/selected/aria-disabled) = 48. hover는 정적 페이지로 재현할 수 없는 상호작용 상태라 제외하고, 클래스·속성으로 켤 수 있는 상태만 나열합니다. 텍스트는 전 타입·전 사이즈 Body/Sm 고정 — Size는 패딩·높이만 바뀝니다.

Underline

.tabs-item-underline — 내부 .tabs-item__content(레이블) + .tabs-item__underline(하단 밑줄 바) 구조가 필수입니다.

Underline (Brand)

.tabs-item-underline-brand — 구조는 underline과 동일, selected 색만 브랜드 블루로 바뀝니다.

Pill

.tabs-item-pill — 내부 슬롯 구조 없이 텍스트만 직접 넣습니다.

Segmented

.tabs-item-segmented — 트랙 배경·보더를 담당하는 .tabs-segment 컨테이너로 감싸야 정상적으로 보입니다.
