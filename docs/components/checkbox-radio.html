Checkbox & Radio & Toggle

Checkbox — Validation × State

normal은 modifier 클래스 없음, valid/invalid는 .choice--valid / .choice--invalid(더블 대시). indeterminate는 HTML 속성이 없어 렌더 후 JS로 el.indeterminate = true를 설정합니다.

Checkbox — Disabled

실제 <input disabled> — 별도 wrapper 클래스 없이 입력 요소의 상태만으로 흐림 처리됩니다.

Radio — Validation × State

.choice-radio modifier로 원형 글리프가 됩니다. Indeterminate 상태는 라디오에 없습니다.

Radio — Disabled

Toggle

Checkbox/Radio와 별도 마크업(.toggle > .toggle__input + .toggle__track > .toggle__knob). 검증 상태 modifier는 없습니다.
